# 02 — Scriptwriting

Scripts follow a fixed documentary arc. Every claim is fact-checked before it ships.

## Structure (8–12 min videos)

```
Hook → Setup → Conflict → Journey → Climax → Resolution → Lesson → CTA
```

- **One killer one-line hook** opens the video.
- **Closing beat** is always a binary question driving comments: *"So — [A or B]? Tell me in the comments."*

## Rules

- Every factual claim is verified against sources before approval.
- No invented dialogue, no fabricated quotes, no dramatized events presented as fact.
- Sentence-level structure: the script is written so each sentence maps to exactly one visual (see [Visuals](04-visuals.md)).
- Script approval is a hard gate — no voiceover until the script is approved.

## Output

- `script.md` — the approved narration script
- Sentence/beat breakdown feeding the timing manifest
