# 06 — Thumbnails

Thumbnails are generated with AI image generation (we use Gemini) and engineered for curiosity — never just illustrating the topic.

## Universal rules

- On-image text is **centered and highlighted**.
- Text must make **visual sense** with the image (e.g. lone-bullet-approaching-the-jet for "80 KILLS / ONE BULLET" — rejected when text and image were disconnected).
- **Curiosity gap:** show something intriguing but unexplained; raise a question; never just illustrate.
- **Synergy rule:** thumbnail text must add a *new* curiosity gap, never restate the video title.
- When revising: deliver the **first corrected version for review** before applying the fix broadly.

## Per-channel styles (never mix across channels)

| Channel lane | Style |
|--------------|-------|
| History | Cinematic photorealistic + elegant white/gold serif |
| Psychology | Black-and-white manga pencil-sketch portrait + huge bold black/red type on textured off-white |
| War stories | Dark cinematic war imagery + bold yellow/red block typography |

## Gate

Thumbnail approval is a hard gate — the pipeline does not move past it without explicit human approval.
