# 08 — Publishing

## Approval rule (non-negotiable)

Upload, schedule, or set public **only** on explicit human approval — e.g. "upload kar do", "go ahead", "theek hai upload karo".

- "OK", "Sure", and ambiguous replies are **never** treated as approval. When in doubt, ask once.
- A vague "Done" during unrelated work is not approval for anything.

## Safety limits

- **Max 1–2 uploads per channel per day.** Never bulk-upload — it triggers YouTube upload caps and processing stalls.
- Review links (unlisted) go to the human for approval on every video.

## Pipeline order

Production is modular and approval-first:

```
research → (approve) → script → (approve) → voiceover → (approve)
  → visuals → assembly → thumbnail → (approve) → metadata → review → publish
```

Remakes redo only the changed stage, never the whole video.
