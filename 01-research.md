# 01 — Outlier Research

Every video starts with evidence. We find recently-published videos that outperformed their small channels, extract the curiosity trigger, then move one step sideways — similar, never identical.

## Target profile

| Criterion | Value |
|-----------|-------|
| Channel age | Created within the last ~6 months (new channels) |
| Subscribers | 1,000 – 20,000 |
| Total videos | Max 25 (verified, no exceptions) |
| Recency ranking | Last 7 days first, then 8–14 days, then older breakouts |

Disqualified candidates are not reported as picks. No established channels, ever.

## Ranking

Within each niche, sort by:
1. **Views** — descending (millions → K)
2. **Recency** — recent → old
3. **Subscribers** — ascending (1K → 20K max)

## Per-outlier report

Each pick documents:
- **Channel** → Outlier Video → Performance → Why It Worked
- **Proven Topic** → 3–5 related original ideas (ranked)
- **Recommended Topic** + "Style to replicate" + reference YouTube link (full watch URL)

## Rules

- **Similar, not identical:** extract the curiosity trigger, move one step sideways. Never copy the original video.
- **Research is reviewed before any topic is finalized.** No exceptions.
- Outlier sources must match the target audience (e.g. English-language, Western-audience videos for Western channels).
- Understand the outlier's *format* deeply — why and how it works — then replicate the format, not the content.
